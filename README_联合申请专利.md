# 企业异地联合申请专利数据

## 数据来源
- 原始来源：马克数据网（上市公司专利申请情况）
- 覆盖范围：上市公司异地联合申请专利，按城市对汇总

## 字段说明
| 字段 | 说明 |
|------|------|
| Prgrvn_i | 省份i |
| Pfgrtn_i | 地市i |
| Prgrvn_j | 省份j |
| Pfgrtn_j | 地市j |
| Year | 会计年度（专利申请年份） |
| Invja | 联合申请的发明数量 |
| Umja | 联合申请的实用新型数量 |
| Desja | 联合申请的外观设计数量 |

## 数据规模
- 时间跨度：2018-2020
- 城市对数量：14,720
- 涉及城市：约350个

## 用途
作为文化基因→创新网络分析的被解释变量（网络中心性）的原始数据来源。
